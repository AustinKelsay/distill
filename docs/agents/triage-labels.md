# Triage Labels

The engineering skills use five canonical triage roles. The repository uses the same strings in GitHub.

| Skill role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is required |
| `needs-info` | `needs-info` | More reporter information is required |
| `ready-for-agent` | `ready-for-agent` | Fully specified and available for AFK implementation |
| `ready-for-human` | `ready-for-human` | Human implementation or judgment is required |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill names a role, apply the corresponding GitHub label from this table.
